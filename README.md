# ob-havo

HTML, CSS va JavaScript yordamida yaratilgan zamonaviy ob-havo ilovasi (Weather App).

## Imkoniyatlari
- OpenWeatherMap API orqali dunyoning istalgan shahridagi real vaqt ob-havo ma'lumotlarini olish
- Harorat (°C), namlik (%) va shamol tezligi (km/h)
- Ob-havo holatiga mos dinamik rasmlar (Quyoshli, Bulutli, Yomg'irli, Qorli va h.k.)
- Shahar nomi noto'g'ri kiritilganda xatolik xabari ko'rsatilishi
- Qidiruv tugmasi va "Enter" klavishi orqali qidirish

## Ishlatilgan texnologiyalar
- HTML5
- CSS3
- JavaScript (Fetch API, Async/Await)
- OpenWeatherMap API
- Font Awesome
